# Privacy

The default synthetic demo runs locally and does not send telemetry or analytics
to the project maintainers.

Pressing **IMPORT OPENF1** requests the session catalog from the external
OpenF1 service. Confirming a session makes additional HTTPS requests and stores
responses in the user's local application-data directory. The provider can
receive standard connection information such as IP address, request time and
user agent according to its own privacy policy.

Race Replay Lab does not include an automatic crash-reporting service. Review
local cache files before attaching them to issues because they may contain data
obtained from third parties.
